# 看板娘用的文件（Live2D）

这个文件夹是首页左下角那个 Live2D 角色用到的全部文件。**放在这里，不放在别人的服务器上**：
页面断网也能打开，也不会因为别人家的 CDN 挂掉就消失。

## 里面有什么

| 文件 | 是什么 | 授权 |
|---|---|---|
| `oml2d.min.js` | 播放器（把 Live2D 模型画到网页上），[oh-my-live2d](https://github.com/hacxy/oh-my-live2d) v0.19.3，979 KB | MIT |
| `Hiyori/` | 角色模型，18 个文件、约 4.8 MB | Live2D 官方免费示例数据 |

`oml2d.min.js` 里已经打包了 Live2D 官方的 Cubism 2 / Cubism 5 运行库（Live2D Cubism Core），
所以不需要再单独放别的文件。

## 怎么改（开关、位置、换模型）

- 开关和模型路径：`../mascot.js` 顶部的 `CONFIG`（`minWidth` 是屏幕宽度门槛，默认 1400 像素）。
- 位置和大小：`../style.css` 末尾的 `#mascot` 那一段。
- 换模型：把新模型文件夹放进本目录，再把 `mascot.js` 里的 `model` 改成新的 `.model3.json` 路径，
  然后照着上面「必须标注的版权」改页脚那行字。官方免费模型清单见
  <https://www.live2d.com/zh-CHS/download/sample-data/>。
