这个文件夹是首页左下角那个 Live2D 角色用到的全部文件。**放在这里，不放在别人的服务器上**：
页面断网也能打开，也不会因为别人家的 CDN 挂掉就消失。

所以不需要再单独放别的文件。

## 怎么改（开关、位置、换模型）

- 开关和模型路径：`../mascot.js` 顶部的 `CONFIG`（`minWidth` 是屏幕宽度门槛，默认 1400 像素）。
- 位置和大小：`../style.css` 末尾的 `#mascot` 那一段。
- **气泡 / 状态条 / 菜单**（2026-09-25 加回来的）：开关在 `../mascot.js` 的
  `tips` / `statusBar` / `menus` 三处，位置和外观在 `../style.css` 末尾。
  三点要注意：
  1. **中英文各一份**：文案表在 `mascot.js` 的 `TEXT` 里（`zh` / `en`），按 `<html>` 上有没有
     `lang-en` 决定用哪份。改文案就改这张表。
  2. **菜单只留了"休息"**：另外三个（切换衣服 / 切换模型 / 关于）在 `style.css` 里按
     `data-name` 藏掉了——仓库里只有一个模型、一套衣服，点那两项会弹"挂载模型失败"。
  3. **气泡和菜单的位置是量出来的，不是照抄库的默认值**。库里按"整个大舞台"算百分比，
     我们的容器只有 150×224，照默认值气泡会被挤成一条竖着小纸条。改了 `#mascot` 的高度/
     模型大小之后，**`bottom` 那几个数要重新量**（容器高度算作 0，内容从 bottom 往下长）。
     状态条是从屏幕左边缘滑出来的竖条，`left: 2px` 是为了不让白描边被屏幕切掉。
- ⚠️ 库里的 `idleTips.wordTheDay` **不要打开**：一打开页面每次都会去连一言 API
  （`v1.hitokoto.cn`），而且弹出来的是网上随机句子，内容不可控。默认就是关的。
- 换模型：把新模型文件夹放进本目录，再把 `mascot.js` 里的 `model` 改成新的 `.model3.json` 路径，
  然后照着上面「必须标注的版权」改页脚那行字。官方免费模型清单见
  <https://www.live2d.com/zh-CHS/download/sample-data/>。
