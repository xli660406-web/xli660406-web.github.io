# 个人主页（第一版）

这是一个**纯静态**网站：只有 HTML / CSS / JS 三个文件，没有数据库、没有外部依赖，
断网也能打开。

## 怎么看效果

在本机浏览器里打开这个文件即可：

```
/home/raspberry/mysite/index.html
```

（文件管理器里双击 `index.html` 也行。）

## 已经做进去的几件事

- 深色底 + 三层背景景深（最远光斑 / 中景光晕 / 网格颗粒），滚动时分层移动
- 首屏大字名字、打字机标签、滚动到哪里淡入到哪里
- 作品卡片鼠标移上去轻轻浮起，邮箱可一键复制，右下角联系方式常驻
- 手机自动减配：关掉模糊背景和跟随光效，只留淡入，避免低端机卡顿
- 系统开了"减少动态效果"时，全站停止动画（晕动症友好）
- 不加载任何外部字体和库，国内打开不会卡在等文件
- 网页标签上有自己的小图标（内嵌矢量，不多下载一个文件）
- 手机上顶部导航不再消失：关于 / 技能 / 在折腾 / 联系 四个入口在小屏上也点得到
- 作品卡片配上了图：图在上、字在下，三张卡片高矮一致；鼠标移上去图会轻轻放大一点
- 音乐墙：一列列专辑封面慢慢往上/往下滑动，鼠标停在某一列上就停下让你看清；手机上只留两列、格子更小
- 音乐墙没加载出脚本时也能看：退化成"一列能自己上下滚"的样子，不会变空白

## 改完之后怎么让网上也变

在这个文件夹里依次执行（需要联网，先跟 Codex 说一声）：

```
git add -A
git commit -m "这次改了什么"
git push
```

推送后 1~2 分钟自动生效。**只改本地文件不推送，网上不会变。**
