# 个人主页（第一版）

这是一个**纯静态**网站：只有 HTML / CSS / JS 三个文件，没有数据库、没有外部依赖，
断网也能打开。

## 怎么看效果

在本机浏览器里打开这个文件即可：

```
/home/raspberry/mysite/index.html
```

（文件管理器里双击 `index.html` 也行。）

## 中英文切换（2026-09-22 加的）

页面顶部导航最右边有个小圆按钮：中文界面显示 `EN`，英文界面显示「中」，点一下整页换语言。
**选过一次就记住了**——存在浏览器里，下次打开（本机双击、或者手机上看网上那份）还是上次那个语言。

英文文字写在哪？**就写在中文旁边**，在同一个标签上：

```html
<!-- 普通一句话：英文写在 data-en 里 -->
<h2 data-en="About">关于我</h2>

<!-- 标签里还夹着链接、加粗的时候：改用 data-en-html，英文里也要把那几个标签写全 -->
<p data-en-html='复刻自 <a href="https://oshwhub.com/...">他的项目</a>'>
  复刻自 <a href="https://oshwhub.com/...">他的项目</a>
</p>

<!-- 图片说明、无障碍标注、照片说明这种写在属性里的字 -->
<img alt="专辑封面：Kiss Me（松下優也）" data-en-alt="Album cover: Kiss Me (松下優也)">
<button data-cap="第 1 步 · 刷锡膏" data-en-cap="Step 1 · Applying solder paste">
```

规则一句话：**属性名前加 `data-en-`**（`alt` → `data-en-alt`，`aria-label` → `data-en-aria-label`，
`content` → `data-en-content`，`data-cap` → `data-en-cap`）。切换逻辑在 `assets/main.js`
第 0 段（有详细注释），两个页面共用一套。

几件事要记住：

- **改中文的时候顺手改英文**，两句话就在同一个标签上，别只改一边
- 软件名、平台名（比如听歌面板里那五家）在 `assets/main.js` 的 `PLATFORMS` 表里，
  每行有 `name`（中文）和 `nameEn`（英文）
- 首屏会打字的那几句在 `assets/main.js` 的 `T.phrases` 里，中文英文各一组
- **歌名、歌手、人名、型号不翻**（它们是名字）；**照片里烧进去的中文也改不了**（实拍图上的字、
  屏幕截图里的界面），这部分英文模式下仍是中文，是正常的

## 改完之后怎么让网上也变

在这个文件夹里依次执行（需要联网，先跟 Codex 说一声）：

```
git add -A
git commit -m "这次改了什么"
git push
```

推送后 1~2 分钟自动生效。**只改本地文件不推送，网上不会变。**
