# 个人主页（第一版）

这是一个**纯静态**网站：只有 HTML / CSS / JS 三个文件，没有数据库、没有外部依赖，
断网也能打开。

## 怎么看效果

在本机浏览器里打开这个文件即可：

```
/home/raspberry/mysite/index.html
```

（文件管理器里双击 `index.html` 也行。）

## 怎么改内容

所有文字都在 `index.html` 里，用编辑器打开，搜到对应中文直接改：

| 想改什么 | 在 index.html 里搜 |
|---|---|
| 大字名字 | `枫言枫语`（网名，出现在首屏大字、导航、网页标题、页脚） |
| 小字本名 | `李育晓`（在首屏小字、关于我第一句、页脚括号里） |
| 首屏那行会动的字 | `main.js` 里的 `phrases` 数组（一组短句轮着打字显示） |
| 关于我 | `我是李育晓，网名「枫言枫语」` 那两段 |
| 技能标签 | 搜索 `tag`（专业 / 兴趣方向 / 在学在玩 三组） |
| "最近在折腾"的卡片 | 搜索 `卡片` 或 `card__title` |
| 音乐墙的歌名 / 歌手 | 搜索 `tile__cap`，`<b>` 里的字是歌名、`<i>` 里的字是歌手（现在 25 张都填好了） |
| 音乐墙的封面图 | 图在 `assets/img/`，从 `music-01.jpg` 到 `music-25.jpg`。换图就用同名文件覆盖，尺寸 400×400（正方形） |
| 点封面后弹出的软件列表 | `main.js` 里的 `PLATFORMS`（一行一个平台：显示的名字 + 搜索地址，地址里的 `{q}` 会被换成歌名和歌手），加一个、删一个都在这儿 |
| 手机上点平台名要唤起哪个 App | 同一张 `PLATFORMS` 表：`app` = App 自己的跳转协议，`pkg` = 安卓包名；哪一家点了没反应就改这两项 |
| 邮箱 | `lyxicl@qq.com`（出现 3 处：联系区、右下角悬浮按钮、复制按钮指向它） |
| 备用邮箱与抖音 | 搜索 `xli660406@gmail.com` |
| GitHub 链接 | `https://github.com/xli660406-web` |
| 作品卡片的配图 | 图都在 `assets/img/` 文件夹里：`project-aigc.jpg`、`project-site.jpg`、`project-pingpong.jpg` 按 1200×750 做；复刻播放器那张 `project-fakepod.jpg` 是正方形 1200×1200（它在宽卡片里是"图左字右"，正方形才不会裁掉两边）。换图把同名文件覆盖掉就行 |

| 项目详情页 | 在 `projects/` 文件夹里，一页一个项目（现在只有 `projects/fakepod.html`）。首页卡片里的标题、配图、底部那行"看详情"都指向它；详情页顶部有"← 回到项目"能回到首页的项目区 |

改完保存，刷新浏览器就能看到。

## 已经做进去的几件事

- 深色底 + 三层背景景深（最远光斑 / 中景光晕 / 网格颗粒），滚动时分层移动
- 首屏大字名字、打字机标签、滚动到哪里淡入到哪里
- 作品卡片鼠标移上去轻轻浮起，邮箱可一键复制，右下角联系方式常驻
- 手机自动减配：关掉模糊背景和跟随光效，只留淡入，避免低端机卡顿
- 系统开了"减少动态效果"时，全站停止动画（晕动症友好）
- 不加载任何外部字体和库，国内打开不会卡在等文件
- 网页标签上有自己的小图标（内嵌矢量，不多下载一个文件）
- 手机上顶部导航不再消失：关于 / 技能 / 在折腾 / 联系 四个入口在小屏上也点得到
- 作品卡片配上了图：图在上、字在下，三张卡片高矮一致；鼠标移上去图会轻轻放大一点
- 音乐墙：一列列专辑封面慢慢往上/往下滑动，鼠标停在某一列上就停下让你看清；手机上只留两列、格子更小
- 点封面会弹出"用哪个软件听"：网易云音乐 / QQ 音乐 / 酷狗音乐 / 汽水音乐 / Apple Music 五选一。**手机上点平台名是先唤起那个 App**（顺手把"歌名 歌手"复制进剪贴板，进 App 长按粘贴就能搜到），唤不起（没装）就自动退回它的网页；电脑上没有这些 App，直接开网页新标签。最下面还有一条"去 B 站搜"给什么都没装的人兜底
- 音乐墙没加载出脚本时也能看：退化成"一列能自己上下滚"的样子，不会变空白

## 改完之后怎么让网上也变

在这个文件夹里依次执行（需要联网，先跟 Codex 说一声）：

```
git add -A
git commit -m "这次改了什么"
git push
```

推送后 1~2 分钟自动生效。**只改本地文件不推送，网上不会变。**

- 点封面后弹出的这几个平台里，**网易云和 QQ 音乐的网页版会引导你装 App 或登录**（2026-09-21 实测：手机上看不到搜索结果），酷狗和 Apple Music 的手机网页能直接看到歌。所以面板最下面那条"去 B 站搜"一直留着，谁都能点开看
- **汽水音乐没有给听众用的网页版搜索**（2026-09-21 实测：官网 `qishui.douyin.com` 只有下载页，`music.douyin.com` 是给音乐人/合作方用的平台）。所以点"汽水音乐"只会打开它的官网——手机里装了 App 的大概率会直接进 App，没装的会看到下载页
- **汽水音乐也没有对外的唤起协议**（它官网脚本里只有自己内部用的 `bytedance://`、`nativeapp://`），所以这一家手机上点下去不会直接进 App
- **2026-09-21 晚修了一个"点了没反应"的 bug**（用户拿手机实测：点「网易云音乐」「QQ 音乐」一点动静都没有，点「汽水音乐」倒是会开网页）。原因不是手机的问题：微信、QQ 这类自带浏览器**根本不允许网页跳 App**，而上一版在跳不动的时候没有任何下一步，等于一条死路。现在的做法：点平台名 → 试着唤起 App，**同时面板上留一行"正在试着打开「××」· 没反应？点这里用网页打开"**——那是个真链接（用户自己点，浏览器不会拦），点它就把面板收掉、打开网页。想完全避开这行兜底，就把网址复制到手机自带的浏览器（Safari / Chrome）里打开，那里的跳转权限是全的
- **手机上"点了到底进没进 App"我在电脑上验不了**（需要一部装了 App 的手机）。我验过的是这套机制本身：手机尺寸下点「网易云音乐」→ 面板不关、那行兜底出现且链接正确；点兜底 → 面板收起、页面恢复滚动；电脑上行为没变（面板直接收起、另开网页）。**请再拿手机点一张封面试一次**，告诉我哪家能进 App、哪家还是不行
- 四个平台的唤起协议来源不一样：网易云 `orpheus://`、酷狗 `kugou://` 是从各家自己的网页脚本里翻出来的（有据可查）；**QQ 音乐的 `qqmusic://` 是按常见写法填的，没找到官方证据**（2026-09-21 晚又去翻了一次它的手机网页，那边 `/m/` 只是个跳转页，没抓到脚本，仍未证实）；Apple Music 不用协议（iOS 打开它的网页链接，系统会交给"音乐"App）
