# 个人主页（第一版）

这是一个**纯静态**网站：只有 HTML / CSS / JS 三个文件，没有数据库、没有外部依赖，
断网也能打开。

## 怎么看效果

在本机浏览器里打开这个文件即可：

```
/home/raspberry/mysite/index.html
```

（文件管理器里双击 `index.html` 也行。）

## 怎么改内容

所有文字都在 `index.html` 里，用编辑器打开，搜到对应中文直接改：

| 想改什么 | 在 index.html 里搜 |
|---|---|
| 大字名字 | `一言先`（网名，出现在首屏大字、导航、网页标题、页脚） |
| 小字本名 | `李育晓`（在首屏小字、关于我第一句、页脚括号里） |
| 首屏一句话 | `水利水电工程专业大一在读，最近迷上了 AIGC 视频` |
| 打字机滚动标签 | `main.js` 里的 `phrases` 数组 |
| 关于我 | `我是李育晓，网名「一言先」` 那两段 |
| 技能标签 | 搜索 `tag`（专业 / 兴趣方向 / 在学在玩 三组） |
| "最近在折腾"的卡片 | 搜索 `卡片` 或 `card__title` |
| 邮箱 | `lyxicl@qq.com`（出现 3 处：联系区、右下角悬浮按钮、复制按钮指向它） |
| 备用邮箱与抖音 | 搜索 `xli660406@gmail.com` |
| GitHub 链接 | `https://github.com/xli660406-web` |

改完保存，刷新浏览器就能看到。

## 已经做进去的几件事

- 深色底 + 三层背景景深（最远光斑 / 中景光晕 / 网格颗粒），滚动时分层移动
- 首屏大字名字、打字机标签、滚动到哪里淡入到哪里
- 作品卡片鼠标移上去轻轻浮起，邮箱可一键复制，右下角联系方式常驻
- 手机自动减配：关掉模糊背景和跟随光效，只留淡入，避免低端机卡顿
- 系统开了"减少动态效果"时，全站停止动画（晕动症友好）
- 不加载任何外部字体和库，国内打开不会卡在等文件
